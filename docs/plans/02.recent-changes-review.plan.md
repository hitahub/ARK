## Review finding

### Wikilink diagnostics should ignore code samples

- **Priority:** Medium
- **Location:** `src/obsidian-plugin/wikilinks.ts:7,15`
- **Issue:** `findUnresolvedWikilinks` scans all Markdown text, so wikilink-like
  text inside fenced or inline code is reported as an unresolved link. This
  can give users misleading diagnostics for code examples.
- **Recommendation:** Exclude fenced and inline code spans before scanning, or
  use a Markdown-aware parser that only processes link contexts. Add coverage
  for wikilink-like text in both kinds of code spans while retaining the
  existing behavior for embeds, aliases, headings, and resolved targets.
