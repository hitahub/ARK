# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests. Public disclosure before a fix is available may put users at risk.

If GitHub's private vulnerability reporting feature is enabled for this repository, use the **Report a vulnerability** option on the repository's Security tab. If that option is unavailable, email [soparsihotang@gmail.com](mailto:soparsihotang@gmail.com).

Please include, when possible:

- The affected version or commit.
- The potential impact.
- A concise description of how to reproduce the issue.
- Relevant environment details.
- Any known workaround or mitigation.

Do not include unrelated personal information, credentials, or private vault contents in a report. Please allow the maintainers to coordinate a response before sharing vulnerability details publicly.
